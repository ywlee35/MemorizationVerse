# 📖 새일꾼반 성경암송 앱

사랑의교회 새일꾼반 성경 구절을 듣고 반복 재생하며 암송하기 위한 웹 기반 학습 앱입니다.

## ✨ 주요 기능

- 📝 **11주차 커리큘럼**: 매주 2개씩 총 22개 성경 구절
- 🌏 **한국어 / English 전환**: 음성과 화면 텍스트(주제·장절·본문)가 함께 전환
- 🗣️ **여성 / 남성 음성 선택**: 4가지 조합 (한국어·영어 × 여성·남성)
- 💾 **선택 기억**: 언어·음성 설정이 브라우저에 저장되어 다음 방문 시 그대로 유지
- 🎵 **제목 + 구절 순서 재생**: 매 재생 시 주제 제목 음성 후 구절 재생
- 🔂 **개별/전체 재생 선택**: 1절만 · 2절만 · 전체(1절+2절) 선택 가능
- ♾️ **무한반복 포함 반복 옵션**: 1·2·3·5·7·10·20회, 무한반복(∞) 지원 (기본값: ∞)
- ⚡ **재생 속도 조절**: 1x, 1.25x, 1.5x, 2x 지원
- ⏩ **구간 탐색**: 진행도 바 클릭으로 원하는 구간으로 이동
- 🎨 **다크 테마**: 장시간 사용에 편한 프리미엄 다크 모드 디자인
- 📱 **모바일 최적화**: 모든 기기에서 완벽하게 작동

## 📂 파일 구조

```
index.html                          # 메인 앱 파일
Audio/                              # 음성 파일 132개
  T01_Christ_the_Center_KO_F.mp3    # 1주차 주제 · 한국어 여성
  T01_Christ_the_Center_KO_M.mp3    # 1주차 주제 · 한국어 남성
  T01_Christ_the_Center_EN_F.mp3    # 1주차 주제 · 영어 여성
  T01_Christ_the_Center_EN_M.mp3    # 1주차 주제 · 영어 남성
  01_Gal_2-20_KO_F.mp3              # 1번 구절(1주차 1절) · 한국어 여성
  02_John_15-5_KO_F.mp3             # 2번 구절(1주차 2절) · 한국어 여성
  ...                               # T01~T11, 01~22 × KO/EN × F/M
README.md                           # 이 파일
```

> **구절 음성 구성**: 본문 → *(쉼)* → 장절
> 장절은 **끝에서 한 번만** 낭독됩니다. 화면 상단에 장절이 이미 표시되므로
> 앞쪽 낭독은 중복이라 제거했습니다.
> 제목 음성은 주제만 낭독합니다.

> **오디오 파일 명명 규칙**
> - 제목: `T{주차 2자리}_{주제 영문}_{KO|EN}_{F|M}.mp3` — 11주차 × 4 = 44개
> - 구절: `{구절번호 2자리}_{장절 슬러그}_{KO|EN}_{F|M}.mp3` — 22구절 × 4 = 88개
> - `KO`/`EN` = 한국어/영어, `F`/`M` = 여성/남성 음성
> - 구절번호는 1~22 통번호이며, `n주차`는 `2n-1`(1절)·`2n`(2절)에 해당합니다
>
> 음성은 ElevenLabs TTS(`eleven_multilingual_v2`)로 생성했습니다.
> 생성 스크립트와 원문 데이터는 저장소에 포함되지 않은 `Docs/` 폴더에 있습니다.

## 🚀 사용 방법

### 1. **주차 선택**
- 상단 탭에서 원하는 주차를 클릭합니다
- 해당 주차의 주제와 성경 구절 2개가 표시됩니다

### 2. **언어 · 음성 선택**
- 상단의 **한국어 / English** 로 낭독 언어를 고릅니다 — 화면의 주제·장절·본문도 함께 바뀝니다
- **여성 / 남성** 으로 음성을 고릅니다
- 기본값은 **한국어 · 여성** 이며, 한 번 고르면 다음 방문 때도 유지됩니다
- 재생 중에 바꾸면 즉시 새 음성으로 다시 재생됩니다

### 3. **재생 모드 선택**
- **1절만**: 제목 → 첫 번째 구절 재생
- **2절만**: 제목 → 두 번째 구절 재생
- **전체**: 제목 → 1절 → 2절 순서로 재생

### 4. **재생**
- ▶ 버튼을 눌러 재생합니다
- 각 구절 카드의 ▶ 버튼으로 해당 절만 바로 재생할 수 있습니다
- 재생 중인 구절 카드는 금색으로 하이라이트됩니다

### 5. **반복 횟수 설정**
- 반복 버튼을 클릭하여 반복 횟수를 선택합니다
- 기본값은 **무한반복(∞)**

### 6. **재생 속도 조절**
- `1x` 버튼을 클릭하여 속도를 변경합니다
- 처음 암송 시 1x, 익숙해지면 1.25x~1.5x 추천

### 7. **주차 이동**
- ⏮ / ⏭ 버튼으로 이전/다음 주차로 이동
